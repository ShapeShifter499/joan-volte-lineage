# System properties LineageOS's added code reads, and what the kit does.
property ro.build.version.incremental LineageOS on joan tells a system update by this alone: PackageManager's upgrade scan and package cache, default permission grants and TeleService's carrier config cache key on it. tools/repack-rom.sh gives the repacked ROM its own, so flashing it over the nightly it came from is an update (tests/check-rom.sh checks); the zip re-dates what it installs (stamp_future) and grants through Calling permissions; a tree build gets a new one per build
property ro.telephony.block_binder_thread_on_incoming_calls False in joan-common's system.prop: onIncomingCall returns no listener and ImsStack answers 480. Set true by device patch 0003, the zip's installer (undone by its uninstaller) and tools/repack-rom.sh; tests/check-rom.sh and the installer tests check it
property ro.telephony.handle_audio_direction_changes_between_call_state_changes Unset on joan, so ringback follows the call's audio direction as in AOSP; tests/check-rom.sh checks the repacked ROM does not set it false
